Notes:
• All internet traffic is HTTPS (port 443) only. No inbound internet access is required on any server.
• The QBetter port (*) depends on their configuration — to be confirmed with QBetter.
• iCure is SaaS-only — all client data is encrypted end-to-end before reaching their servers.
• All API calls are authenticated via Bearer JWT tokens. No implicit network trust.
