Notes:
• All traffic uses port 443 (HTTPS). No inbound internet access is required on any LAN server.
• ticketing-agenda access scope (TBD): if all city buildings are on a corporate WAN or site-to-site VPN, ticketing-agenda can be restricted to LAN/VPN only and moved off the DMZ. ticketing-service stays in the DMZ regardless, as citizens always connect from the internet.
• The QBetter port (*) is to be confirmed.
• iCure is SaaS-only. All client data is encrypted end-to-end before leaving the browser.
• All API calls require a valid Bearer JWT token.
